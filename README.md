# DeepSeek Harness Native — development

The target is a resource-efficient native Linux application without Electron and without a mandatory primary webview. Tauri is not a requirement. The original webview carrier is retained as integration research, not a finished native app.

## Source repositories

- Native UI, lifecycle, transport and benchmark source: [IOUJared/deepseek-harness-native](https://github.com/IOUJared/deepseek-harness-native).
- Same-version backend fork, with upstream history and MIT notices retained: [IOUJared/deepseek-harness-linux](https://github.com/IOUJared/deepseek-harness-linux).

Clone the two repositories into sibling directories named `deepseek-harness-native` and `deepseek-harness-linux`. Build the backend using its documented pnpm build, then build the native app with `cargo build --locked --release -j2 --manifest-path deepseek-harness-native/app/Cargo.toml`. See the [native application instructions](app/README.md) for explicit runtime, private-home and Node options. This is development source, not a self-contained or parity-qualified release.

Private runtime homes, credentials, generated evidence/reports/screenshots, compiled binaries and dependency caches are intentionally **not published**. Historical documentation links into those local evidence directories will not resolve in a fresh GitHub clone; the benchmark measurement summaries are retained, but underlying raw runs are local. Historical references to the earlier sibling Tauri research checkout are not current native-app dependencies. The development packaging script still expects that checkout's local Cargo source cache and needs a relocatable-cache follow-up; publication does not claim clean-machine packaging reproducibility. The native crates already declare MIT; the root [license](LICENSE) mirrors the existing lifecycle-core license. Dependency and Slint redistribution requirements remain separate.

## Current status

- [Iced 0.14.0 with GPU rendering is selected](docs/TOOLKIT-DECISION.md) for the initial primary UI. [Eight corrected release runs](benchmarks/results-comparison-03/MEASUREMENTS.md) pass native Wayland, app_id and scale/geometry checks after internal snapshot inspection. At scale 1, Iced GPU measures 74.48 MiB RSS and 3.92% of one core during scrolling, compared with Slint GPU's 96.02 MiB and 10.42%. These are synthetic frontend measurements, not integrated app memory or universal toolkit rankings.
- The [benchmark runner](benchmarks/run.py) and [analyzer](benchmarks/analyze.py) retain honest startup proxies and owned process-tree RSS/PSS, CPU and available DRM VRAM counters. Redraw requests and GPU submissions are not compositor presentation. Fifteen headless measurement/phase/geometry tests pass; genuine compositor fractional scaling and input/presentation latency remain unmeasured.
- The [private desktop supervisor](../deepseek-harness-tauri/runtime/FORK-README.md) has 37 mock tests. Host/Client halves and optional browser assets now build. The [real isolated fork smoke](smoke-home/fork-backend-hS3o50/result.json) passes 12 checks: startup, private lifecycle, workspace registration, keyless onboarding/account reads, subscription disposal, unauthenticated rejection and native authenticated HTTP. No model call or account mutation was issued; browser/Office capabilities remain unavailable, not full parity.
- The [native Rust lifecycle core](core/README.md) now has 44 minimal-core/46 transport-enabled passing fixture tests and four compile-fail privacy tests per mode, including a consuming API-key persistence capability. It stages the same isolated supervisor, owns Node on a persistent thread, bounds control I/O and keeps launch/platform credentials out of public events. Its [real-Harness smoke](smoke-home/core-backend-fcuuh3b9/result.json) also passes: temporary startup-worker survival, readiness, idle inspection, keyless account/onboarding/subscription lifecycle, workspace registration and graceful exit zero with no observed descendants remaining. The optional authenticated transport composition now also compiles and preserves those privacy tests; this library is not the finished native application.
- The [Rust HTTP/WebSocket transport](transport/README.md) passes 19 fixture test groups and one Agent/Session identity compile-fail doctest and a [real integrated keyless smoke](smoke-home/native-transport-4afvu20x/result.json): private authentication, workspace/event/control baselines, session creation/listing, actual snapshot/page records, stream disposal, immediate Core-stop credential revocation and graceful shutdown. No prompt/model-catalog request was made. These results qualify the backend connection, not full native UI parity.
- The [real Iced application](app/README.md) now builds in release and passes 83 shared app/component tests (86 in the composed developer fixture), with explicit native approvals/untimed questions and masked API-key settings with review/confirmation, one-use secret input and honest indeterminate writes. Own reply RPC ACKs retire pending deliveries without inventing tool execution; malformed positional requests and stale/cancelled replies fail closed. Parent-owned [native qualification](docs/NATIVE-APP-QUALIFICATION.md) verifies actual Wayland mapping, real workspace/session/snapshot loading, own rendered Rosé Pine frames at application scales 1 and 1.25, and clean bounded shutdown with zero model requests. A measured 11.4%-of-one-core idle regression was traced to global process enumeration and corrected with fenced owned-descendant traversal; the short optimized keyless run measures median 0% at sampling resolution, ~327 MiB whole-tree RSS and ~249 MiB PSS. These are not long-chat or full-parity performance results.
- Native account/browser/legacy-plugin compatibility remains implementation work. Web content must load only when requested, in isolated guest contexts without main-app secrets or generic native permissions.

- The [real public-fixture API-key smoke](smoke-home/api-key-public-fixture-22xiqsvu/result.json) verifies the official default provider's acknowledged write, metadata refresh and isolated 0600 local storage using only a fixed public fake value. No real key/model/account sign-in is involved. [Composed actual native UI→worker→Core/default-provider PUBLIC-dummy saving](<docs/NATIVE-COMPOSED-SETTINGS.md>) now also passes matching real ACK, separate private-file/metadata verification, masked native rendering and clean Wayland shutdown at application scales 1/1.25. Physical keyboard/pointer/IME input and real-key validity remain unqualified; source-only default-provider side-effect review is not a network trace.
- The [full feature status](docs/FEATURE-PARITY.md) keeps implemented, fixture-tested and live-qualified behavior distinct. Timed/continued questions, real decision-dialog execution, settings and broader desktop capabilities are not advertised as complete.

## Remaining gates

1. Complete and qualify data-backed Iced workspace/session/chat/tool/approval/settings flows using the composed native lifecycle and authenticated transport. The [transport reference](docs/NATIVE-TRANSPORT.md) documents exact alpha envelopes and lifecycle requirements, not a completed UI.
2. Implement lazy isolated account/browser/legacy-plugin compatibility and native terminal/file/document flows without handing arbitrary guests main-app authority.
3. Repeat representative release measurements and qualify interactive input, accessibility and integrated process-tree performance before release.
4. Add Linux lifecycle/install/update integration, qualify end-to-end parity and package artifacts. Keep external Linux account/update infrastructure limits explicit.

No parity-qualified release or archive has been delivered. Existing installed Harness data, profiles, credentials and the browser GUI remain separate. Benchmarking changes neither compositor/display settings nor global fonts, themes, icons or bindings. Application-controlled 1.25 scaling is distinct from genuine compositor fractional scaling.

Slint's distribution-license option must be reviewed before release; Iced is MIT. A private prototype does not accept a proprietary distribution license on the user's behalf or change the MIT license of the independent Harness backend. Version evidence: [Slint](https://crates.io/api/v1/crates/slint/1.18.1) and [Iced](https://crates.io/api/v1/crates/iced/0.14.0).
