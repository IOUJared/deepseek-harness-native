## Launch

Extract the archive, rebuild the matching companion source tag using its normal public profile build workflow, then run the extracted launcher with explicit absolute paths:

```sh
./launch.py --runtime /ABS/deepseek-harness-linux/apps/cli --workspace /ABS/project --user-home /ABS/private-user --data-home /ABS/native-data
```

Requires external Node26, Python3.11+ launcher tooling, full exact-alpha base+Web profile, Wayland, fonts and GPU/system libraries. Local grants/drafts are private plaintext, not encryption or issuer revocation. Catalog/account metadata is not verified entitlement.

Not standalone/installer/AppImage, general Linux/Windows/macOS portability, live OAuth/provider/quota/reset/alerts/retry, physical input/accessibility, complete redistribution licensing, adversarial containment, power-loss, signatures, reproducibility or new performance certification. Historical private evidence links in guides are not public downloads.
