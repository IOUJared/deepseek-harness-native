## Limits

- No native UI qualification, no per-case PUBLIC capture set and no frame-by-frame comparison in this archive; the extracted startup check is two keyless runs with one inspected frame each.
- No live OAuth/provider/login/quota/model generation, physical input, IME/CJK, accessibility, compositor fractional scaling, installer/AppImage/self-contained runtime, Windows/macOS, complete redistribution licensing, signatures, reproducibility or performance certificate.
- Launch still requires the separately rebuilt `0.2.1-alpha.1` backend, Node 26, native Wayland, GPU/EGL/Vulkan drivers, xkbcommon and system fonts. The archive is not an installer and bundles neither Node nor the backend. Python is not required by the native launcher; it remains required only by the repository's qualification scripts.
- Node in these runs is the development machine's **26.12.0**, not the CI runner's pinned 26.10.0.
- Local private evidence, screenshots and qualification homes stay off GitHub; no historical private link is a public download.

## Launch

```sh
./launch --runtime /ABS/deepseek-harness-linux/apps/cli --workspace /ABS/existing/workspace \
  --user-home /ABS/private-user-home --data-home /ABS/new-private-native-container
```

Add `--check` for prerequisites only, or `--qualify-evidence /ABS/owned-empty-0700-evidence --scale 1.25` for the keyless qualification used above. `--data-home` must name a **new** container that does not exist yet; an existing directory is refused.
