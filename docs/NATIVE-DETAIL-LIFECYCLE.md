## Local routing

- Opener lease binds generation, prior consumed global opening identity and record key, including live preview. Successful opening consumes once; stale/closed-generation requests cannot reopen reused keys.
- Back/Formatted/Source carry exact visible frozen-panel stamp. Settings/export/management/decisions/close/shell covers suppress effective visibility.
- Context-bearing keyboard subscription stamps Escape. Old queued Escape cannot dismiss a newer panel; generic `DismissPanel` closes covers, **not Details**. Cover dismissal preserves frozen source.
- Checked app-global counter never resets on selection. Exhaustion disables opening; last valid Back/mode remains usable. Missing key/live stream consumes nothing.
- Disconnected panels remain readable/dismissible. Source is bounded reducer display resolved at opener delivery, **not full wire/final reply or per-record revision lease**.
