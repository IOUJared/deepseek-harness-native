# Native Linux development package

## Scope

This is an **external-runtime development archive**, not a standalone installer, AppImage, system installation or update channel. Its Iced/wgpu executable uses no Electron or mandatory primary webview. A same-version **built isolated alpha CLI runtime** must already exist; the installed RC runtime is not compatible. Model calls, account/browser flows, optional tools and plugin installation are not certified offline merely because the executable archive is local.

Two source-backed pnpm 11.7 offline/ignore-scripts deployments were attempted in separate new private staging directories: bare CLI failed on absent `@agentclientprotocol/sdk@1.4.0` mirror metadata; complete production closure failed on absent LibreOffice-kit metadata. No downloads/install scripts were requested. Legacy deploy forces unfrozen resolution and hoisted mode disables lockfile use; additional flag permutations are not a qualified substitute for missing cache metadata. Partial staging is retained, not included in this archive. A self-contained Host closure remains a release gate, including required peers, one Cordis identity, materialized vendor links, published assets/native modules and closure-specific license obligations.

## Run

Extract into a new directory you own; do not overwrite a prior build. The launcher must stay at the archive root alongside its manifest and executable directory. Python 3.11+ and a **Node major 26 interpreter** are required. The default is fixed `/usr/bin/node`, never PATH; optional `--node /absolute/node-executable` selects and probes that executable, validates its canonical executable-regular-file path, and passes the same selection to the native app. Use only a trusted executable: version parsing is not authentication, a sandbox or exec-time inode binding. Core and downstream tools still have fixed `/usr/bin:/bin` PATH; this does not bundle Node libraries or the Host. Only Node 26.10.0 on this Arch x86_64 host is presently qualified. ELF symbol inspection currently requires **glibc 2.44**; the launcher refuses older glibc rather than presenting a broadly compatible Linux build. Other 26.x patches, distributions, newer glibc versions, kernels, drivers and optional tools are not automatically certified. The package requires a native Wayland session; it does not silently use XWayland. Fonts, GPU/Vulkan/EGL/Wayland libraries and tools are system-provided.

```sh
./launch.py --workspace /absolute/existing/workspace \
  --runtime /absolute/isolated-alpha-fork/apps/cli --check

./launch.py --workspace /absolute/existing/workspace \
  --runtime /absolute/isolated-alpha-fork/apps/cli
```

`--check` reads package/runtime manifests, checks the native executable digest, paths and data marker, and invokes only the selected Node's version command (system default when omitted). Explicit `--node` therefore executes the selected program even during `--check`; no PATH or system fallback occurs on rejection. It creates no data/lock, opens no GUI and starts no Host. Its `prerequisites-valid` result does **not** prove complete dependency resolution or successful runtime startup. The digest is consistency against the accompanying manifest, not a signature or authenticity guarantee.

User home defaults only to explicit `--user-home` or `HOME`. Mutable native storage defaults to a separate build-SHA-qualified directory under that user's `.local/share`; the parent must exist. `--data-home /absolute/new-container` chooses another new private location. The launcher refuses unknown existing containers, another build's marker, symlink/nonprivate Host children and overlap with the package/runtime, default `.dsh`, or inherited `DSH_HOME`. A new container/Host directory is 0700, marker and lock are 0600. Failed startup may retain this private container; there is no automatic removal, rollback, old-profile adoption or migration. Changed builds default to different storage, preserving old data rather than silently converting it. This is accidental-overlap protection, not arbitrary-profile filesystem confinement.

A nonblocking advisory lock prevents overlapping launcher use of the same container. Its descriptor survives launcher→native exec and may also be inherited by the owned Node process; a surviving inheritor may hold it after the GUI exits. No helper stays resident merely to supervise the native process. Directory-fd checks and a post-acquisition inode check detect ordinary acquisition-time replacement; they do not eliminate subsequent same-UID pathname races. Preserve the data directory while the app is active.

The launcher forwards selected locale/Wayland/session variables and retains inherited `DSH_HOME` only as Core's exclusion, never as a storage default. Model/API keys, launch cookies, `NODE_OPTIONS`, `LD_PRELOAD`, arbitrary DSH variables and X11 display are not forwarded. Trusted custom profile providers/hooks may have other effects; no network-trace or adversarial containment guarantee is made.

## Package and source contents

The archive contains the release native executable, launcher, explicit external-runtime manifest, these instructions, selected native app/Core/transport source and Cargo lock/manifests, upstream/native MIT notices and available cached Rust dependency license texts with a **lockfile-superset** inventory. It excludes runtime npm modules, Electron, browser/Python/Office sidecars, model/provider binaries, real credentials/profiles/session data, evidence screenshots, Cargo caches and target directories. Inventory is not a certification of every compiled third-party contribution; public redistribution/legal review remains a separate release gate. External runtime components retain their own license obligations, including Office engines if separately redistributed.

## Relocated keyless qualification

```sh
./launch.py --runtime /absolute/isolated-alpha-fork/apps/cli \
  --workspace /absolute/owned-empty-0700-workspace \
  --user-home /absolute/owned-empty-0700-user-home \
  --data-home /absolute/new-private-native-container \
  --qualify-evidence /absolute/owned-empty-0700-evidence --scale 1.25
```

This explicit opt-in creates one PUBLIC blank session in a fresh isolated profile, sends no model prompt/catalog request, captures only its own Iced renderer and requests native graceful shutdown after eight seconds. Reports/images are create-new mode 0600. The new native `--smoke-evidence-root` option admits only an explicitly selected existing owned 0700 directory; omission preserves the old source-local evidence restriction. No smoke output is automatically sent to the old compilation checkout. This is scripted startup/lifecycle/paint qualification, not real keyboard/pointer/IME input, generation, rich attachments, all settings/exports or full parity. Filesystem/kernel delays are not bounded by a universal hard shutdown deadline.

Current source launcher/qualifier scripts share strict observed Node version validation and add the actual patch and accepted major to prerequisite-only `--check` output. This does not certify every accepted patch or change Core's direct-launch API. Accepted output limits apply after buffered subprocess capture, not adversarial output-allocation protection.
